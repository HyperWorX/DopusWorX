# Getting started

![A Markdown file open in Reading mode, with the mode and Save buttons in the top toolbar](images/reading.png)

1. Install DopusWorX (see the main README), then open any supported file in the
   Directory Opus viewer pane or the pop-out viewer window.
2. For a Markdown file, switch between **Reading**, **Live** and **Source** in the
   top toolbar. Click Source again for the split preview.
3. Edit in Live or Source and save with the toolbar Save button, or turn on
   auto-save. Save As and Save a Copy are on the Save menu.
4. Open **Settings** (the gear icon) to choose a palette, set fonts and spacing,
   turn maths on, customise the toolbar, and map which file types open in
   DopusWorX.
